# 🎮 GamePython — A Flask-Based Web Game

**GamePython** is a simple web-based game built using **Python Flask**, **HTML**, and **CSS**. This project demonstrates the integration of a Python backend with a dynamic front-end interface, ideal for beginners exploring web development and game logic.

---

## 🚀 Features

- 🎯 Interactive gameplay via web browser  
- 🌐 Built using Flask framework  
- 🎨 Styled with responsive CSS  
- 📁 Clean folder structure and easy to deploy  
- 🧠 Game logic handled using Python
